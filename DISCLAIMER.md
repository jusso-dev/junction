## What Junction is

Junction is a convenience tool that brings Microsoft's published APIs together
under one command-line interface, Rust library, MCP server and local HTTP API.
It reads Microsoft's publicly available API definitions and documentation, and
sends requests that you choose to make, with credentials that you supply.
